滴答清单 · 任务创建方法

AppleScript 自动化方案

适用场景：助理通过 AI 助手（Bingo）远程为老板创建任务
⚠️

遇到的问题

为什么不能直接用 API？

  • ✗ 滴答清单官方未开放 Open API，第三方无法直接调用
  • ✗ 钉钉、飞书等 IM 工具无法直接与滴答清单对接
  • ✗ 助理需要频繁在多个应用间切换，操作繁琐
✅

解决方案

用 AppleScript 直接操控滴答清单 Mac 版

1
Mac 自带 AppleScript 脚本语言，无需安装任何第三方工具
2
直接向滴答清单应用发送指令，添加任务到清单
3
任务自动同步到手机端，手机端可直接查看和提醒
⌨️

核心命令

复制到终端（Terminal）即可执行

Terminal 命令
# 带截止时间 + 优先级 osascript -e 'tell application "TickTick" to add task given title:"任务标题", due date:"2026-05-20T15:00:00+0800", priority:3'
💡 带额外属性（due date / priority）时，必须用 given 关键字，否则会报错
📋

参数说明

title / due date / priority 完整释义

title （必填）
任务名称，如："开会""提交方案"
due date （可选）
截止时间，格式：YYYY-MM-DDTHH:mm:ss+0800
priority （可选）
0=无 1=低 3=中 5=高
应用路径
/Applications/滴答清单.app
💡

使用示例

直接复制下面的命令，粘贴到终端即可

📅 明天15点截止
osascript -e 'tell application "TickTick" to add task given title:"开会", due date:"2026-05-20T15:00:00+0800", priority:3' ✓ 中优先级
🚀 高优先级紧急
osascript -e 'tell application "TickTick" to add task given title:"紧急方案", due date:"2026-05-19T18:00:00+0800", priority:5' ✓ 高优先级
📝 无截止日期
osascript -e 'tell application "TickTick" to add task given title:"待办事项"' ✓ 无截止 · 无优先级
⏰ 今天17点前完成
osascript -e 'tell application "TickTick" to add task given title:"提交周报", due date:"2026-05-19T17:00:00+0800", priority:3' ✓ 中优先级
